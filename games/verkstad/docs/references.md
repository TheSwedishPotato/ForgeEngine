# Where the numbers come from

Looked up for this game on 2 November 2026. A **found** number comes from the source given. A
**~** number is the value commonly quoted for the car, or engineering judgement, and it is the
first thing to check against a workshop manual. No factory workshop manual was read for any of
these cars.
